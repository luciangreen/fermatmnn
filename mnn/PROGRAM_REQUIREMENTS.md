# Program Requirements

This implementation follows the staged MNN requirements in `../pr1.txt` and provides:

1. Explicit domains, concepts, facts, claims, questions, rules, dependencies, constraints, examples, and tasks.
2. Deterministic reasoning with provenance-aware output.
3. Choice packets and splice operations.
4. Dependency graph and necessary-input analysis.
5. Small algorithm synthesis and generated Prolog output.
6. Basic optimisation reports, scheduler, research classification, verification helpers, and benchmark harness.
7. A number-theory domain demonstrating compositeness vs probable-prime evidence.
